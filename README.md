# 📱 Antigravity Mobile Remote (Standalone CLI)

برنامه مستقل، ترمینال‌محور و محلی (Local-First) برای کنترل و نظارت بر ایجنت هوش مصنوعی **Antigravity** به شکل کراس‌پلتفرم بر روی **ویندوز و لینوکس**. این ابزار امکان استریم زنده خروجی، مشاهده وضعیت کارت‌های ابزار، ورودی صوتی و فیدبک‌های لرزشی را مستقیماً از روی گوشی موبایل (نظیر Samsung Galaxy S24) در شبکه محلی فراهم می‌سازد.

---

## ✨ ویژگی‌های برجسته

- 💻 **برنامه مستقل و بدون وابستگی به ادیتور:** بدون نیاز به نصب هیچ‌گونه افزونه روی VS Code؛ به صورت یک برنامه مستقل خط فرمان (CLI / TUI) اجرا می‌شود.
- 🪟🐧 **کراس‌پلتفرم کامل:** سازگاری تضمین‌شده با محیط‌های لینوکس و ویندوز، شناسایی خودکار باینری‌های `agy` و خاتمه ایمن پردازش‌ها.
- ⚡ **۱۰۰٪ محلی و بدون تأخیر ابری:** ارتباط مستقیم کلاینت گوشی با کامپیوتر روی شبکه Wi-Fi خانگی با پینگ کمتر از ۲ میلی‌ثانیه بدون نیاز به اینترنت، پروکسی یا سرورهای خارجی.
- 📷 **کیوآرکد آنی در ترمینال:** تولید خودکار QR Code استاندارد در خط فرمان جهت اتصال با دوربین موبایل تنها با یک اسکن.
- 📡 **استریم زنده و کارت‌های ابزار:** مشاهده لحظه‌ای پاسخ‌های متنی، جریان تفکر (Reasoning)، کارت‌های ابزار (`run_command`, `view_file`, `write_to_file`) و گزارش توکن‌ها.
- 📳 **فیدبک لرزشی و صوتی هوشمند:** پشتیبانی از Web Audio API و Haptic Feedback موبایل برای اعلام پایان تسک‌ها.
- 🎙️ **ورودی صوتی (Voice Input):** تبدیل گفتار به متن مستقیم روی گوشی با Web Speech API.
- 📱 **پشتیبانی کامل از PWA:** قابلیت Add to Home Screen در مرورگرهای Chrome و Samsung Internet برای اجرای تمام‌صفحه و تجربه نیتیو.

## 🚀 شروع سریع با نصاب هوشمند

پروژه مجهز به یک نصاب تعاملی است که تمام پیش‌نیازها را بررسی کرده و با تایید مرحله‌به‌مرحله شما برنامه را آماده اجرا می‌کند:

### در لینوکس یا مک:
```bash
./install.sh
```

### در ویندوز:
روی فایل `install.bat` دابل‌کلیک کنید، یا در PowerShell دستور زیر را اجرا کنید:
```powershell
.\install.ps1
```

یا مستقیماً با Node.js:
```bash
npm run setup
```

> [!TIP]
> برای مشاهده راهنمای گام‌به‌گام و تفصیلی به زبان فارسی، مستند [راهنمای راه‌اندازی (GUIDE.md)](./GUIDE.md) را مطالعه نمایید.

## 🎛️ مرکز کنترل و مدیریت تعاملی (TUI Management Center)

جهت مدیریت ساده و همه‌جانبه پروژه بدون نیاز به تایپ دستی دستورات، می‌توانید از رابط کاربری متنی تعاملی (TUI) استفاده نمایید:

```bash
./manage.sh
# یا
npm run manage
```

**امکانات مرکز کنترل TUI:**
- 🚀 **استارت الان (Foreground):** اجرای مستقیم در محیط ترمینال با خروجی رنگی و کد QR.
- ▶️ **استارت سرویس:** راه‌اندازی پس‌زمینه از طریق `systemctl --user`.
- ⏹️ **استاپ و ری‌استارت سرویس:** متوقف‌سازی و بارگذاری مجدد پردازش‌های سرویس.
- 📜 **مشاهده لاگ‌های زنده:** لاگ‌گیری بی‌درنگ با `journalctl -f` بدون خروج از محیط منو.
- 🌐 **اصلاح و تنظیم پروکسی:** تشخیص خودکار پروکسی محلی سیستم (مانند SOCKS5 یا HTTP)، تزریق متغیرها در فایل سرویس و بارگذاری مجدد daemon.
- 🛠️ **نصب و بازسازی مجدد:** بیلد، لینک و نصب پکیج‌ها با یک کلیک.
- ⚙️ **سوئیچ شروع خودکار:** فعال یا غیرفعال‌سازی سرویس در بوت سیستم.

## ⌨️ کلیدهای میانبر در حین اجرا (Interactive Hotkeys)

در حین اجرای برنامه، نیازی به متوقف کردن سرور نیست. کلیدهای زیر در محیط ترمینال فعال هستند:

| کلید | عملکرد |
| :---: | :--- |
| `r` | چاپ مجدد کد QR و آدرس‌های سرور |
| `o` | باز کردن آدرس وب در مرورگر پیش‌فرض سیستم |
| `c` | پاک کردن تاریخچه گفتگوهای جاری |
| `s` | نمایش وضعیت آنلاین، آدرس و کلاینت‌ها |
| `w` | نمایش دایرکتوری کاری فعال (Workspace) |
| `h` | نمایش راهنمای دستورات |
| `q` یا `Ctrl+C` | بستن ایمن سرور و پروسه‌ها |

## ⚙️ گزینه‌ها و سوییچ‌های خط فرمان (CLI Options)

```bash
antigravity-remote [گزینه‌ها]
```

- `-p, --port <number>`: تعیین پورت سرور (پیش‌فرض: `7788`)
- `-w, --workspace <path>` یا `-d, --dir <path>`: پوشه کاری هدف برای پروژه‌ای که ایجنت در آن فایل‌ها را تغییر می‌دهد (پیش‌فرض: پوشه جاری)
- `-e, --effort <low|medium|high>`: تنظیم سطح تفکر مدل (پیش‌فرض: `low`)
- `-o, --open`: باز کردن خودکار مرورگر سیستم پس از اجرا
- `--no-qr`: عدم چاپ کد QR در ترمینال
- `-v, --version`: نمایش شماره نسخه
- `-h, --help`: نمایش راهنما

## 🔄 اجرای در پس‌زمینه (Systemd Service)

برای لینوکس، فایل سرویس آماده در مخزن قرار دارد:
```bash
mkdir -p ~/.config/systemd/user
cp antigravity-mobile-remote.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now antigravity-mobile-remote.service
```
